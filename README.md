# 🌦️ Live Weather App

A modern and responsive weather application that provides real-time weather updates, 5-day forecasts, and air quality data using OpenWeatherMap API.

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡️ Real-time temperature updates  
- ☁️ Weather condition (Clear, Clouds, Rain, Mist, etc.)  
- 📅 Current date & time display  
- 📊 5-day weather forecast  
- ⏰ Hourly temperature updates  
- 💨 Air Quality Index (CO, NO2, O3, SO2)  
- 🌅 Sunrise & Sunset timings  
- 📱 Fully responsive UI  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- Bootstrap 5  
- jQuery  
- OpenWeatherMap API  

---

## 🔑 API Used

- OpenWeatherMap API  
👉 https://openweathermap.org/api
